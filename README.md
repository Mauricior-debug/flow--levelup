# LEVELUP

A personal development app for Expo Go. Loop is the companion. Daily missions, goals, XP, and chats stay on the device.

## Run

```bash
npm install
npx expo start
```

Open the project in Expo Go for SDK 58. The preview channel is recorded in `wren-preview.json` after publish.

## Screens

Onboarding: Welcome, Meet Loop, Focus, Current situation, Daily time, Motivation, Generating the plan, Plan ready, First win, Create account, Sign in.

Tabs: Home, Progress, Loop, Goals, Profile.

Also: Chat, Mission sheet, Inbox, Streak calendar, New goal, Goal detail, New habit, Achievements, Celebration, Account, Notifications, Theme, Privacy, Subscription, Connected devices.
